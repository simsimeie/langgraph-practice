# 07. 고급 기능

## 개요

LangGraph의 고급 기능들을 다룹니다.

## 주요 고급 기능

### 1. 서브그래프 (Subgraph)
복잡한 그래프를 작은 단위로 분리하고 재사용하는 패턴입니다.

```
메인 그래프
  │
  ├── [서브그래프 A] (독립적인 State와 로직)
  │        └── 내부 노드들
  │
  └── [서브그래프 B]
           └── 내부 노드들
```

### 2. 병렬 실행 (Parallel Execution / Fan-Out)
여러 노드를 동시에 실행해서 속도를 향상시킵니다.

```
[분기 노드]
    ├──▶ [노드 A] ──┐
    ├──▶ [노드 B] ──┼──▶ [수집 노드]
    └──▶ [노드 C] ──┘
```

### 3. Map-Reduce 패턴
큰 데이터를 청크로 나눠서 병렬 처리하고 결과를 합칩니다.

```
[원본 데이터]
    │
    ▼ (분할)
[청크1] [청크2] [청크3]
    │       │       │
    ▼       ▼       ▼
[처리1] [처리2] [처리3]
    │       │       │
    └───────┴───────┘
            │
            ▼ (합산)
        [최종 결과]
```
